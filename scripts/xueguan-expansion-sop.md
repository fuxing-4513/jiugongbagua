# 易学书馆 · 古籍扩充 SOP（标准作业流程）

> 目标：135 → 300+ 部华人圈核心古籍。质量铁律：**只收公版原典 + 九宫导读/白话标注**，绝不批量 AI 生成充数。

## 〇〇〇、录文原则（珍稀馆藏著录后填实——不造假铁律）

> **录文（敦煌残卷等）只在有可靠底本时填写：**
> - 底本三源：①馆藏原卷照片目验转录（需视觉能力/人工——我无此能力时不做）②**公版旧录文**（1900-1940s 出版——过保护期）③**开放授权录文**（CC-BY 等——如 CBETA）
> - **绝不用 AI 编造/生成敦煌原文**——无源宁缺
> - 现代学术校录（黄正建/陈于柱等 2000s 著作）**有版权——不照录**
> - 录文数据字段：luwen { source(底本), text[], notes }——著录页有录文才渲染该区
> - 用户提供公版/授权文本 → 立即格式化入库

## 〇〇、图文数据铁律（用户原话级要求——最高优先级）

> **古籍中的卦象、图谱、插图等（卦画/河图洛书图/星峰图/异兽图/结构示意）是研究的原始数据——千万不可省略、不可用"（此处有图）"占位了事。**
> - 收录任何带图古籍 → 图必须落地（三种方式：①原书扫描图（公版源提取）②程序化数据图重建（卦画/数图/关系图——SVG）③尽力线描示意）
> - 入库前必须跑图引用扫描：`node -e "..."` 检查 content figures src 全部指向存在的文件（81 处引用曾 17 处缺失——教训）
> - 卦象类（周易 64 卦）已程序化生成：`scripts/gen-hexagram-svg.js` 可复用/再生
> - 文字可按九宫特色归纳整理——图不可省

## 〇、版权合规红线（最高优先级——每本书入库前必过 4 查）

> **知识产权风险零容忍**——任何一本有版权瑕疵的书都不入库。用户明确要求严格规避。

| # | 检查项 | 通过标准 | 操作 |
|---|---|---|---|
| 1 | **作者卒年** | 作者逝世 ≥ 50 年（中国著作权法：50 年保护期）；或明确古代作者（明清以前一律安全） | 查作者生平；**近现代作者（民国以后活跃者）逐个核卒年**——韦千里(1988 卒)✗、谈养吾(1976 卒)✗、邵伟华(在世)✗——一律不收 |
| 2 | **文本来源声明** | 底本页带 **PD-old / 公版标记**（维基文库 `{{PD-old}}`），或来源机构明确声明公版 | 采维基文库只采带 PD-old 页；ctext 可采（明确公版声明） |
| 3 | **非现代整理本** | 不收"现代人校注/点校/译注本"正文（整理者有演绎著作权）；只收**原典原文** | 若底本附现代注释——只录原文正文 |
| 4 | **不收现代创作** | 1900 年后成书的术数著作默认怀疑（除非作者卒年确认 ≥ 50 年，如沈竹礽 1906 卒 → 公版 ✓） | 民国玄空/近代命理书逐个核 |

**已核实公版可采**：所有古代典籍（明清及以前）+ 沈氏玄空学（沈竹礽 1906 卒）。
**明确禁收**：邵伟华、韦千里、谈养吾、钟义明等近现代作者作品；现代出版社的整理本正文。
**文库（用户自创）**：用户自己的原创文章无版权问题——但转载/引用他人内容必须标注或不用。

## 一、采集源可用性（2026-09-05 实测）

| 源 | 状态 | 说明 |
|---|---|---|
| ctext.org（中国哲学书电子化计划） | ⚠️ 需会话 | HTTP 200 但 GET 空（反爬）——需带 cookie/模拟会话，或人工复制文本 |
| zh.wikisource.org | ⚠️ 需甄别 | 多数道教/术数典籍是 **scan 转写**（pages 索引 PDF——无内联文本不可采）；仅**全文模板页**（`<poem>`/纯文本）可采 |
| gushiwen.cn | ⚠️ 版权模糊 | 页面排版有版权主张——仅参考校对，不直接复制 |
| 汉典 zdic.net | 词典为主 | 可辅助查字 |

**可采集判断法**：wikisource 页 `?action=raw` 若含 `<pages ...>` = scan 版（放弃）；若为纯 wikitext/`<poem>` = 文本版（可采）。

## 二、数据格式（对齐现有架构）

接入一本书 = 3 步：
1. **正文**：`src/data/xueguan/content/{book-id}.ts`（复制 `_REFERENCE_TEMPLATE.ts`）——含：
   - `metadata`（sourceOrg: 'jiugong-bagua' / sourceVersion 注明底本）
   - `preface`（**九宫导读**——原创概要/按语/阅读建议/版本说明——GEO 引用点）
   - `chapters`（`{id, title, content}` 按卷/篇拆分——**白话语译章节可加 `vernacular` 字段、注释加 `notes`**）
2. **注册**：`content-registry.ts` 加 import + 注册条目
3. **书目**：`books.ts` 的 `bookCatalog` 加 `{id, title, author, dynasty, category, summary, keywords, volumes, isComplete: true}`
4. 验证：`npx tsc --noEmit` + 本地 dev 看 `/xueguan/[category]/[book-id]`
