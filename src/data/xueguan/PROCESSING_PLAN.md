# 易学书馆 · 古籍全文收录计划

**总书目：** 数百部
**预估总字数：** ~555 万字
**当前完整状态：** 道德经(81章)✅ 周易(10/64卦)🔶 其余均为占位简介❌

## 收录原则

1. **先重后轻** — 先做用户高频查看的命理/卜筮核心书
2. **先短后长** — 先做章节少、字数短的书，快速出成果
3. **同类集中** — 同一类别一起做，保持风格一致
4. **本版优先** — 优先选用王弼本、通行本等最广泛版本
5. **九宫特色** — 每本加导读 + 元数据标记

## 工序规范（每一本的完整流程）

```
1. 【来源选择】确定所用版本（王弼本/通行本/影印本/辑录本）
2. 【文本获取】↓ 低峰期用 web_fetch 从公共站点取原文
3. 【深度清洗】去除网站水印、页码、注释、广告、外链
4. 【章节划分】按原书结构拆分为 ≤3000 字章节
5. 【格式化】按标准模板写入 TS 文件
6. 【加九宫层】写导读 + 设 metadata 元数据
7. 【注册】在 content-registry.ts 中添加引用
8. 【终审】你过目确认品质
9. 【上报】标记 isComplete: true
10.【部署】npm run build → gh-pages
```

## 节奏建议

- 每批 3-5 本做一次终审，不要攒太多
- 短书（<1万字）一批做 5-8 本
- 长书（>10万字）单独做，每本终审一次
- 写导读时保持九宫风格统一，可以用同一段开头模板
